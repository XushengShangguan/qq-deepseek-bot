# 大肥鱼使用手册

这份手册讲怎么和大肥鱼相处，以及怎么照看跑着她的服务器。第一次部署请看 [deploy/README.md](../deploy/README.md)，项目整体介绍见 [README](../README.md)。

下文的 `服务器IP` 换成你自己的服务器地址，命令默认都在 Mac 终端里运行。

---

## 一、准备什么

| 东西 | 用途 | 说明 |
|---|---|---|
| DeepSeek API key | 她的脑子 | 在 [platform.deepseek.com](https://platform.deepseek.com) 充值；自由时间也会花钱，开销可以在后台账单里看 |
| 一个 QQ 小号 | 她的 QQ | **别用大号**。非官方协议有被风控的风险 |
| 一台云服务器 | 让她 24 小时在线 | 2 核 2 GB 够用，系统选 Ubuntu |
| Server酱 或 Bark（可选） | 掉线时提醒你 | 不依赖 QQ 的推送渠道 |
| 小黑盒小号（可选） | 让她逛小黑盒 | **别用大号**，简介里写明是 AI |

---

## 二、和她聊天

用你的 QQ 私聊她的小号就行。只有 `QQ_ALLOWED_USERS` 名单里的人能和她聊，其他人发的消息她看不到。

### 她怎么说话

- 一次回一到三条，每条很短，像真人打字，会有一点延迟。
- 你连发几条，她会等两秒，合在一起回。
- 她是朋友，不是客服，也不是女友：会损你、会不同意你，也会有自己感兴趣的事。

### 能发给她的东西

| 你发 | 她会 |
|---|---|
| 文字 | 正常聊 |
| 图片 | 看图，然后聊图里的内容 |
| 表情包 | 看懂意思；觉得好用就自己收藏起来 |
| PDF / Word（.docx） | 读完，接下来 6 小时里都能聊这份文件 |
| 链接 | 聊天时**打不开**链接，只看得到你写的字 |

不支持语音、视频、.doc（老版 Word）、扫描版 PDF（没有文字层）。

### 让她帮你整理东西

先发文件，再说要什么，比如：

> 帮我把这份讲义整理成复习笔记

需要整理成文档的，她会**做成 PDF 文件发回来**，聊天里只说一两句。如果只是问「这讲讲了啥」，她就直接在聊天里回答，不会生成文件。

最长：文件一次最多 20 MB；放进她脑子里的内容最多约 4 万字，再长的部分她看不到。

### 让她去逛

聊天时她说「我去逛逛」之类的话，一分钟后就真的会去刷 B 站、贴吧或小黑盒。她知道自己答应过回来跟你讲，逛完会来找你，**这一次不受下面的次数限制**。逛的期间你发消息，她照常回。

### 她在小黑盒上

她用自己的小号逛帖子、评论、回复别人给她的留言、在盒友杂谈发帖。另外三件是她自己要的：

- **定时发帖**：写好帖子、定个时间（七天以内），到点自动发。发出去没有，她下次自由时间会知道。
- **翻旧帖**：能翻到自己发过的帖、评论和回复（带帖子号），接话时接得上。
- **给自己定量**：比如「今晚回复最多三句」。定了以后到量就真的发不出去，到时间自动解除。

聊天时她也知道自己有这个号、最近发了什么、还有哪些定时帖没发。

### 她主动找你

- 她自己的自由时间平均每 90 分钟一次，凌晨 1 点到 8 点（她的时间）在睡觉。
- 有想分享的东西才会找你。默认每人每天最多 1 次；`LIFE_CHATTY_FRIENDS` 里的人默认最多 4 次、两次之间至少隔 3 小时，可以用 `LIFE_CHATTY_MAX_PER_DAY`、`LIFE_CHATTY_GAP_MINUTES` 调，比如设成 `1000` 和 `0` 就是不限。
- 你那边晚上 11 点到早上 9 点不会主动找你。
- 你们刚聊过（20 分钟内）也不会再单独找你。

## 三、看看她最近怎么样

服务器的调试接口只对服务器本机开放。先在 Mac 上开一个隧道，这个终端窗口要一直开着：

```bash
ssh -L 3000:127.0.0.1:3000 root@服务器IP
```

然后在浏览器打开：

| 地址 | 能看到 |
|---|---|
| http://127.0.0.1:3000/api/life | 她的自我画像、最近的成长笔记、日记、主动发过的消息、刷到的热梗、收藏的表情包 |
| http://127.0.0.1:3000/api/memory?companion=大肥鱼&user=qq:你的QQ号 | 她记住了关于你的哪些事、你们的关系数值 |

想马上看她逛一次（会花一点 token）：

```bash
ssh root@服务器IP 'curl -s -X POST localhost:3000/api/life'
```

会返回她这一趟每一步干了什么。

## 四、调整她

### 改人设

人设在 `companions/大肥鱼.txt`：

- 第一段是她是谁；
- `###ENDSEEDCHAT###` 后面是背景。

她的朋友都是谁、和每个人什么关系，写在 `companions/大肥鱼.private.txt` 里，一行一个人。这个文件不进 Git，所以可以放真名，部署时会照常同步到服务器，加载时拼在背景最前面。

改完运行一次 `deploy/update.sh root@服务器IP` 就生效。只改人设不需要重新编译，但脚本会照常编译一遍，等几分钟就好。

调人设的经验：

- **写判断，不写禁令，也不写例句。** 例句会被她照抄，禁令会让她变得拘谨。
- **长度靠数字控制**，比如「一条一般几个字到二十来个字」。
- 改之前先弄清楚她那一轮实际收到了什么，再动手。

### 改频率和开关

在服务器上编辑 `/opt/companion/.env.local`，改完重启程序：

```bash
ssh root@服务器IP 'cd /opt/companion/deploy && docker compose up -d app'
```

常用项（完整列表见 [.env.local.example](../.env.local.example)）：

| 变量 | 默认 | 作用 |
|---|---|---|
| `LIFE` | on | 关掉就没有自由时间了 |
| `LIFE_INTERVAL_MINUTES` | 90 | 自由时间的平均间隔 |
| `LIFE_SLEEP_HOURS` | 1-8 | 她的睡觉时间 |
| `LIFE_MAX_MESSAGES_PER_DAY` | 1 | 每天主动找每个人几次，0 = 从不 |
| `LIFE_CHATTY_FRIENDS` | 空 | 可以多找几次的人（QQ 号，逗号分隔） |
| `LIFE_CHATTY_MAX_PER_DAY` | 4 | 上面这些人每天最多被主动找几次 |
| `LIFE_CHATTY_GAP_MINUTES` | 180 | 两次主动找他们之间至少隔多久 |
| `QQ_MAX_PIECES` | 3 | 一次回复最多几条 |
| `STICKERS` | on | 表情包功能 |
| `HEYBOX_COMMENTS_PER_DAY` | 3 | 小黑盒每天最多主动评论几条 |
| `HEYBOX_REPLIES_PER_DAY` | 5 | 每天最多回复几条别人给她的留言 |
| `HEYBOX_POSTS_PER_DAY` | 1 | 每天最多发几篇帖（发在 `HEYBOX_POST_TOPIC`，默认 7214 = 盒友杂谈） |
| `HEYBOX_SAME_POST_PER_DAY` | 5 | 同一个帖子一天最多主动评论几次 |
| `HEYBOX_SAME_COMMENT_REPLIES` | 5 | 同一条留言最多回几次 |
| `HEYBOX_ERRORS_BEFORE_PAUSE` | 5 | 一天碰到几次人机验证 / 登录过期就暂停一天 |

### 自我画像跑偏了

画像是从她的成长笔记里归纳出来的。偶尔会归纳歪，比如把一次赌气当成性格。可以让她从头重新归纳一次：

```bash
ssh root@服务器IP 'curl -s -X POST "localhost:3000/api/life?action=rebuild-portrait"'
```

## 五、维护

### QQ 掉线了

**表现**：收到 Server酱 / Bark 推送「掉线」，或者发消息她不回。

非官方协议的小号隔几天会被踢下线一次，属于正常现象。重新登录：

1. 先看 NapCat 是不是自己快速登录上了：
   ```bash
   ssh root@服务器IP 'docker logs --since 10m napcat 2>&1 | grep -aE "接收|发送|二维码已保存" | tail -3'
   ```
   看到「接收」「发送」就是已经在线了。
2. 没登上的话，取登录二维码：
   ```bash
   ssh root@服务器IP 'docker exec napcat cat /app/napcat/cache/qrcode.png' > qrcode.png && open qrcode.png
   ```
   用**小号**的手机 QQ 扫码。二维码 2 分钟过期。
3. 扫的时候提示「过期」：先看二维码是什么时候生成的：
   ```bash
   ssh root@服务器IP 'docker exec napcat stat -c %y /app/napcat/cache/qrcode.png'
   ```
   如果是几分钟前的，说明 NapCat 没在刷新二维码。重启它，等 10 秒再取一次：
   ```bash
   ssh root@服务器IP 'cd /opt/companion/deploy && docker compose restart napcat'
   ```

如果登录被拒、提示「账号存在安全风险」，说明小号被风控了。过几个小时再试，并且减少她的发言量：调小 `QQ_MAX_PIECES` 和主动消息的次数。

### 小黑盒登录过期

**表现**：收到推送「大肥鱼的小黑盒停了」。她会自动停一天。

用小号重新扫码登录，步骤见 [deploy/README.md 第 5 节](../deploy/README.md)。扫码前确认手机上小黑盒 App **登着的是小号**：登录成功后脚本会打印 `heybox_id`，和你大号的对一下，不一样才对。

### 更新代码

```bash
deploy/update.sh root@服务器IP
```

- 脚本会先停掉程序，再编译新版本，大约 5 分钟。编译期间 QQ 一直在线，只是她暂时不回消息。
- 编译失败，或者超过 30 分钟，会自动回到旧版本。
- 改了依赖（`package.json`）或 Dockerfile 时编译会慢很多，大约 15–20 分钟。

### 服务器卡死

**表现**：SSH 连不上，ping 得通但没有响应。

1. 去云服务器控制台**强制重启**。重启后 NapCat 和程序都会自动启动，QQ 通常能自动快速登录。
2. 阿里云的系统镜像默认 `vm.swappiness=0`，交换空间形同虚设，编译时容易把内存撑爆导致卡死。`setup-server.sh` 已经改成 60。旧服务器可以手动检查一下：
   ```bash
   ssh root@服务器IP 'cat /proc/sys/vm/swappiness'   # 应该是 60
   ```

### 备份

她的一切都在服务器的 `/opt/companion/data/` 里：聊天记录、记忆、画像、日记（`companion.db`），表情包（`stickers/`），小黑盒登录（`heybox.json`）。数据库运行时有写入，不要直接复制，用在线备份：

```bash
ssh root@服务器IP 'docker exec companion-app node -e "require(\"better-sqlite3\")(\"/app/data/companion.db\").backup(\"/app/data/backup.db\").then(()=>console.log(\"ok\"))"'
scp root@服务器IP:/opt/companion/data/backup.db ./companion-$(date +%F).db
scp -r root@服务器IP:/opt/companion/data/stickers ./stickers-$(date +%F)
ssh root@服务器IP 'rm /opt/companion/data/backup.db'
```

建议每周或每月做一次。服务器坏了也不怕：新服务器部署好以后，把这两样放回 `data/` 就行。

### 看日志

```bash
ssh root@服务器IP 'cd /opt/companion/deploy && docker compose logs --since 30m app'      # 回复、自由时间、报错
ssh root@服务器IP 'cd /opt/companion/deploy && docker compose logs --since 30m napcat'   # QQ 收发、登录
```

自由时间的日志以 `LIFE:` 开头，她干的每一步都在里面。

## 六、常见问题

**她不回消息了。** 按顺序排查：

1. QQ 掉线：见上面「QQ 掉线了」。
2. 正在部署：等编译完。
3. 程序挂了：看 `docker compose ps` 里 `companion-app` 是不是 healthy。
4. DeepSeek 余额用完了：看 app 日志里有没有 402 / 余额不足的报错。

**她说她发了图片 / 打开了链接，其实没有。** 聊天时她只能打字和发收藏的表情包，打不开链接。她编出来的 `[图片]` 之类的标记会被程序自动删掉；如果还是经常出现，调一下人设里对应的那句判断。

**她老是找我 / 太久不找我。** 调 `LIFE_MAX_MESSAGES_PER_DAY`、`LIFE_CHATTY_FRIENDS`、`LIFE_CHATTY_GAP_MINUTES`。

**一个月要花多少钱？** 主要看聊天量和自由时间的频率。在 DeepSeek 后台按天看账单，嫌贵就调大 `LIFE_INTERVAL_MINUTES`，或者设 `LIFE=off`。

**能让别人也和她聊吗？** 把对方的 QQ 号加进 `QQ_ALLOWED_USERS`，在 `QQ_USER_NAMES` 里写她怎么称呼对方，最好再在 `companions/大肥鱼.private.txt` 里写一句她和这个人的关系。她对每个人的记忆是分开的，但自我画像和日记是同一份。
